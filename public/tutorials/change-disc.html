Change Game Disc Tutorial

Swap game discs or change games without losing progress

Launch

Open BeckerBox

Connect Remote(s)

Scan the QR code to connect remotes. Click on the button below for more help if needed

Navigate to Wii Menu

1. Click the start button if not already running

2. Ensure you are on the Wii Menu

Open Options

Tap the options button at the top left of Player One's remote

Change Game Disc Tutorial

Tap Change Disc

Select

Scroll to a desired game, then tap Select

Enjoy!

The game disc has now been inserted

It may take up to 30 seconds before the disc has been fully loaded and displays itself on the system menu
