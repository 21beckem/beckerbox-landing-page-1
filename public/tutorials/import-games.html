Import Games Tutorial

Bring your game files into BeckerBox so you can play them.

Obtain Wii Game Files

Make sure you have a Wii Game file ready

Launch

Open BeckerBox

Click Open

Click the Open Games Folder button

Move Game Files

Move game file(s) into the folder window that appears

Enjoy!

No need to restart BeckerBox. Simply close the folder window and pick up where you left off
